# Фоны профиля

Положите сюда файлы фонов для профилей пользователей.

## formats
Поддерживаются любые изображения (jpg, png, webp).

## backgrounds.json
Манифест доступных фонов. Каждый элемент:
- `key` — уникальный ключ фона (сохраняется в БД)
- `title` — отображаемое имя
- `preview` — имя файла превью в этой же папке
- `vip` — true, если фон доступен только VIP-пользователям

Пример:
```json
[
  { "key": "default", "title": "По умолчанию", "preview": "default.jpg", "vip": false },
  { "key": "deep_space", "title": "Глубокий космос", "preview": "deep_space.jpg", "vip": true }
]
```

Фон 적용яется на страницу профиля и на публичную карточку игрока в галерее.
